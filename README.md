# TIL-Reaction-Diffusion-Modeling

Particle-based reaction-diffusion simulations for exploring whether media viscosity can modulate the fraction of antibody binding events attributable to the same cell that activated the antibody (`f_same`).

The model is implemented in Python using ReaDDy and was run in a conda environment.

## Repository contents

- `TILModel.py` — runs a single ReaDDy simulation condition.
- `ViscositySweep.py` — runs a viscosity or Damköhler-number sweep.
- `Analysis.py` — summarizes result JSON files and generates plots.
- `requirements.txt` — Python package requirements.

## Setup

Create and activate a conda environment, then install the required packages:

```bash
conda create -n readdy-model python=3.12
conda activate readdy-model
pip install -r requirements.txt
```

ReaDDy may require conda-specific installation depending on platform. If `pip install readdy` is unavailable, install ReaDDy using the recommended conda route for your system, then install the remaining packages from `requirements.txt`.

## Run

Run the full sweep:

```bash
python ViscositySweep.py
```

Analyze generated results:

```bash
python Analysis.py sweep_results.json
```

Run a single condition manually:

```bash
python TILModel.py <D_cell> <output.h5> <N_steps> <k_cleave> <k_bind> <r_cleave> <r_bind>
```

Example:

```bash
python TILModel.py 1.0 output_test.h5 1000000 1.0 0.01 8.0 10.0
```

## Outputs

- `*_result.json` — result file for each simulation condition.
- `sweep_results.json` — combined sweep results.
- `sweep_plot.png` — summary plot generated by the analysis script.

## Notes

This is an initial implementation of the modeling framework. Several parameters are phenomenological placeholders and require empirical calibration before quantitative predictions can be made. In the current version, binding events may be too rare for reliable statistical inference.
